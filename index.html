Shuttle Charge Allocation Tracker

An interactive walkthrough of a monthly shuttle-charge allocation workflow: employee self-reporting, department-admin charge-number entry, a non-invasive bridge into a legacy finance workbook, and admin completion tracking.

⚠️ Demo notice: This mockup recreates the logic of a real internal workbook using a fictional company ("NovaWorks Corp", Riverside Campus), fictional employee names, and fictional charge numbers. No real company data is shown.

How the process connects, end to end

Five stages carry one shuttle charge from an employee's submission all the way to the finance team's ledger — without anyone re-typing or reformatting data by hand.

1

Employee submits

Employee pastes their name, date, home department, and one charge number into a shared response form.

→
2

Admin tracks completion

A dashboard flags who has responded, who is missing, and generates ready-to-send BCC reminder lists.

→
3

Admin splits the number

Pasting one hyphenated charge number auto-splits it into six finance segments — no manual parsing.

→
4

Finance view mirrors it

A read-only view shows the same six segments, already lined up in finance's expected column order.

→
5

Legacy workbook untouched

The existing finance pivot workbook consumes those columns as-is — its structure is never redesigned.

Admin — Charge Number Entry

Rather than redesign the finance owner's workbook, the department admin pastes one hyphen-delimited charge number here. Formulas instantly split it into the six fields finance needs — BU, OU, Dept, Account, Project, Activity.

This mirrors the real formula logic: one pasted string, six parsed fields, zero manual re-typing.
